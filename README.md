# 公開検証：仕事のまとめ道具

架空データを使う公開検証用Pluginです。会議要約の `meeting-summary` と調査メモの `research-brief`、[資料の書式](skills/research-brief/references/report-format.md)を同梱しています。

## 使い方

- 会議要約：「この架空の会議記録から、決定事項・未解決の論点・次のアクションを整理してください。」
- 調査メモ：「この架空の案件について、提供資料をもとに要点・根拠・次のアクションを短くまとめてください。」

Agent Plugins対応環境で利用できます。追加ライブラリ・専用認証・元Agentへのアクセスは不要です。外部調査には利用環境の検索機能と必要な権限、または出典資料を用意してください。検証には組織の情報利用ルールに従った架空データを使い、顧客情報や認証情報は含めないでください。
