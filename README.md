# Research & Meeting Kit

調査結果を短い提案資料にまとめるSkillと、会議の記録を整理するSkillをまとめたPluginです。

## 含まれるSkill

| Skill | 内容 |
| --- | --- |
| `research-brief` | テーマ・読者・判断したいことを確認し、一次情報と出典をもとに「要点・根拠・次のアクション」の順で簡潔な資料を作ります。書式は `skills/research-brief/report-format.md` にあります。 |
| `meeting-summary` | 会議の記録から決定事項、未解決の論点、次のアクションを分けて整理します。担当や期日が書かれていないものは「未定」とし、推測で埋めません。 |

## セットアップ

追加の設定、外部サービス、認証情報は必要ありません。

## 使い方の例

- 「この調査メモを、来週の検討会向けの提案資料にまとめて」
- 「この議事録から決定事項と次のアクションを整理して」
